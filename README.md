# 🏠 Home Booking Design

A modern and user-friendly **Home Booking UI Design** created to provide a simple experience for users to explore homes, view property details, and make booking decisions.

## ✨ Features

* 🏠 Home listing page
* 🔍 Search homes and properties
* 📍 Location-based property details
* 🖼️ Property image gallery
* 💰 Display property pricing
* 📅 Booking interface
* ❤️ Favourite properties
* 📱 Clean and responsive UI
* 🎨 Modern and attractive design

## 🛠️ Tools & Technologies

* Figma
* UI/UX Design
* Wireframing
* Prototyping
* Responsive Design

## 📱 Screens Included

* Splash / Welcome Screen
* Home Screen
* Search Screen
* Property Listing
* Property Details
* Booking Screen
* Booking Confirmation
* Profile Screen

## 🎯 Objective

The main objective of this project is to design a **simple, attractive, and user-friendly home booking application interface** that allows users to easily discover properties and proceed with booking.

## 🎨 Design

The complete UI/UX design was created using **Figma**, focusing on clean layouts, easy navigation, and a smooth user experience.
